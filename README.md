# 销售工作台正式版

## 已整理需求

系统按可扩展工作台设计，当前包含两个功能域：

### 活动经营

- 协会基础信息：协会名称、跟进销售、入会成本、关键人姓名、关键人电话、关键人职务、其他联系人、其他联系人电话、协会说明。
- 生态伙伴基础信息：生态伙伴名称、跟进销售、合作成本、关键人姓名、关键人电话、关键人职务、其他联系人、其他联系人电话、生态伙伴说明。
- 基础信息名称不可重复，只能停用，不能删除；管理员负责录入和维护。
- 协会活动登记：协会、活动日期、活动类型、跟进销售自动带出、活动花费成本、参与人数、添加微信数量、产生线索数量、成交金额、活动照片附件、活动说明。
- 协会活动类型：企业参访、小型沙龙、讲座活动、主办活动、大型活动及晚宴、关键人拜访、关键人招待、官方软文推送。
- 生态伙伴拜访登记：生态伙伴、拜访日期、拜访类型、跟进销售自动带出、活动花费成本、参与人数、添加微信数量、产生线索数量、成交金额、活动照片附件、活动说明。
- 生态伙伴拜访类型：日常拜访、协同会议、伙伴活动参与。
- 活动明细区分协会活动明细和生态拜访明细，不展示状态字段。
- 活动完成后支持追加跟进，累计更新微信、线索、成交，并保留每次跟进日期、说明和增量数据。
- 数据看板归属活动经营，支持按协会/生态伙伴、销售、协会名称查询并实时计算指标。
- 管理员查看、编辑、导出全部数据；销售查看全部数据，但只能修改自己负责的活动和跟进。

### 周会记录

- 每周五 14:30 开周会，周报日期固定为当周周五。
- 填写人从当前账号识别，不再重复选择销售姓名。
- 周报按 Excel 模板三列展示：事项、重点关注、本周填写内容。
- CRM 拜访打卡和线下商机拓展活动支持上传照片。
- 销售业绩、签管一体化专项、老客户续费、大流量客户、其他客户等，均按重点关注拆成独立填写项。
- 销售可查看全部周报，只能编辑自己的周报；管理员可查看和编辑全部周报。
- 周报汇总按周五日期展示，可展开/收起；持续保留历史周报。
- 每个销售后有 AI 分析按钮；汇总顶部有团队 AI 分析按钮。
- AI 分析输出管理者结论、重点关注、周会追问、会后管理动作，并支持管理员批注和保存。
- 周会汇报可手动切换汇报人，完整展示销售周报。

## 启动

```bash
python3 server.py
```

然后打开 <http://127.0.0.1:4173/>。

首次启动会自动创建 `sales_workbench.sqlite3` 和 `uploads/`。首次启动密码必须通过环境变量 `SALES_WORKBENCH_BOOTSTRAP_PASSWORD` 设置；如果未设置，服务会生成一次性随机密码并打印到启动日志。请不要把这个密码提交到代码仓库。

- 管理员：`admin` / 首次启动日志中的密码
- 销售：`wangxiao` 等 / 首次启动日志中的初始密码

正式部署前请通过环境变量修改管理员密码，并把 `uploads/` 放到持久化磁盘或对象存储。

## 正式化边界

本版已经具备服务端 SQLite 持久化、结构化接口、文件上传目录、CSV 导出和数据驱动分析引擎。真实生产环境还应接入公司统一身份认证、HTTPS、对象存储、数据库备份和真实大模型服务；页面已按接口边界设计，后续可替换分析引擎而不改周报结构。
